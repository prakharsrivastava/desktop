# Agentic Email Intelligence Assistant

AI-powered email analysis for health insurance operations.

## Endpoints
- `POST /analyze`  — Analyze structured email input
- `POST /upload`   — Upload .eml / .msg file
- `GET  /health`   — Health check
- `POST /token`    — JWT login

## Run
```bash
pip install -r requirements.txt
python main.py
```
